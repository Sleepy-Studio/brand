# Sleepy Studio Site Kit

Reusable reference documentation distilled from `Sleepy-Studio/sitesite` for Sleepy Studio web projects.

This kit documents the framework, design tokens, layout rules, interaction patterns, branding integration, component expectations, accessibility requirements, and adoption guidance needed to make sibling projects visually and structurally consistent without copying project-specific application logic.

## Source

Primary reference repository:

- `Sleepy-Studio/sitesite`

## Intended consumers

- SleepyRadio
- New Sleepy Studio landing pages
- Product microsites
- Internal project portals
- Documentation frontends
- Small browser-first applications that should look like part of the same organization

## Core position

The kit is a reference layer, not a shared runtime package yet. Projects should adopt the documented conventions while keeping their own domain logic, routes, and feature components isolated.
