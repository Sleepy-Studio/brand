# Contributing to Sleepy Studio Brand Assets

## Request an Asset

### How to Request

1. **Check the inventory** — See [CHANGELOG.md](CHANGELOG.md) for what's already available
2. **Open an issue** — https://github.com/Sleepy-Studio/branding/issues
3. **Use the template** — Provide details below:

### Request Template

```markdown
## Asset Request

**What do you need?**
- Description: [brief description]
- Format(s): SVG / PNG / GLB / Other
- Use case: [where/how this will be used]
- Urgency: [low / medium / high]

**Context**
- Which repo/platform will use this?
- Is this blocking other work?

**Reference**
- Mock-up or inspiration link (if applicable)
- Design specs or requirements
```

## Suggest Improvements

Found an issue with an existing asset? Have an idea to improve it?

**Open an issue** with:
- Which asset (exact filename)
- What needs improvement
- Suggested solution
- Priority level

## Asset Guidelines

When contributing new assets, follow these standards:

### Logos
- ✅ Provide SVG (preferred) + PNG backup
- ✅ Support multiple color variants (black, white, colored)
- ✅ Include versions with/without text/tagline
- ✅ Size: maximum 50 KB per file

### Characters/Mascots
- ✅ PNG format, transparent background (PNG)
- ✅ Minimum: 1000px width/height
- ✅ Multiple poses/expressions if available
- ✅ Size: maximum 100 KB per file

### 3D Models
- ✅ GLB format (GLTF binary)
- ✅ Optimized for web (under 1MB ideally)
- ✅ Include preview image
- ✅ Document model scale, units, and rig info

### All Assets
- ✅ High quality, sharp/clean rendering
- ✅ Consistent with brand guidelines
- ✅ Descriptive filename: `asset-name-variant-version.format`
- ✅ Include metadata: artist, date, version, usage rights

## Review Process

1. **Submit** → Open issue or PR with asset
2. **Review** → Brand team reviews for quality/brand alignment
3. **Feedback** → Comments on PR or issue thread
4. **Approval** → Merged when approved
5. **Deploy** → Added to main branch, available on CDN within 1 hour

## Brand Guidelines

All assets should align with Sleepy Studio brand standards:
- **Color palette**: Primary (navy/dark blue), Secondary (red accent), Neutral (white/grays)
- **Tone**: Friendly, approachable, modern yet relaxed
- **Style**: Clean, minimalist aesthetic
- **Accessibility**: High contrast, readable at small sizes
